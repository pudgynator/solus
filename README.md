# Solus

Solus is a landing page for a mental well-being service. Visitors can learn how to find a licensed therapist, explore wellness programs, and get in touch. 

The live site is at https://pudgynator.github.io/solus/.

The page is a single static site built with HTML and CSS.

## What’s on the page

- **Home** — introduction and a way to get started
- **How it works** — browse therapists, book a session, and begin
- **Services** — mindfulness and meditation, one-on-one therapy, and wellness coaching
- **Testimonials** — short notes from clients
- **Partners** — logos of partner brands
- **Resources** — articles, meditation, and workshops
- **Community** — an invitation to join a support space
- **FAQ** — common questions, opened from the question itself
- **Contact** — email, phone, address, and a message form
- **Footer** — navigation, social links, and a prompt to find support

## Layout

The desktop layout is a wide, centered page. On smaller screens the header turns into a menu button, multi-column sections stack, type and spacing tighten, and illustrations scale down so they stay inside their cards.

## View it locally

Open `index.html` in a browser.
